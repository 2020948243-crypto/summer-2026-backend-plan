#### 算法刷题
- [ ] 题目1：LC239. 滑动窗口最大值
        学习一个新的数据结构：大顶堆（优先队列）即通过特定的排序方式，加入新的数。
        用大顶堆维护滑动窗口的最大值，每次加入新的数时，将新的数加入堆中，判断当前最大值是否在窗口范围内。peek()得到堆顶元素，即可得到当前滑动窗口的最大值。
        PriorityQueue<int[]> pq = new PriorityQueue<int[]>(new Comparator<int[]>(){
            public int compare(int[] part1, int[] part2){
                return part1[0] != part2[0] ? part2[0] - part1[0] : part2[1] - part1[1];
            }
       });
       pq.offer(元素)：入队     pq.peek()：返回堆顶元素
       pq.poll()：出队

- [ ] 题目2：LC41.缺失的第一个正数
        因为题目要求时间复杂度为 O(n) 并且只使用常数级别额外空间。
        因此不能额外开辟空间，所以考虑原地哈希，键为元素值，值为数组索引。
        利用数值和下标天然的映射关系，通过正负号标记数字是否出现。
