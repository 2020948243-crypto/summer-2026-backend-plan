## Linux命令笔记

### 文件操作
- ls：列出文件
- cd：切换目录
- pwd：显示当前目录
- mkdir：创建目录
- rm：删除文件/目录
- cp：复制文件
- mv：移动文件

### 文件查看
- cat：查看文件内容
- less：分页查看
- head：查看开头
- tail：查看结尾
- grep：搜索内容

### 权限管理
- chmod：修改权限
- chown：修改所有者
- chgrp：修改所属组

### 进程管理
- ps：查看进程
- top：实时进程监控
- kill：终止进程
- bg：后台运行
- fg：前台运行

### 网络命令
- ifconfig/ip：查看网络配置
- ping：测试连通性
- netstat/ss：查看端口
- curl/wget：下载文件

### Docker命令
- docker run：运行容器
- docker ps：查看容器
- docker build：构建镜像
- docker stop：停止容器
- docker rm：删除容器

### 常用快捷键
- Ctrl+C：终止当前进程
- Ctrl+D：结束输入
- Ctrl+Z：挂起进程
- Tab：自动补全
