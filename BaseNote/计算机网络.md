## 计算机网络笔记

### OSI七层模型
1. 物理层
2. 数据链路层
3. 网络层
4. 传输层
5. 会话层
6. 表示层
7. 应用层

### TCP/IP四层模型
1. 网络接口层
2. 网络层（IP）
3. 传输层（TCP/UDP）
4. 应用层（HTTP, FTP, DNS）

### TCP三次握手
1. SYN
2. SYN+ACK
3. ACK

### TCP四次挥手
1. FIN
2. ACK
3. FIN
4. ACK

### HTTPS流程
1. 客户端发起请求
2. 服务器返回证书
3. 客户端验证证书
4. 协商对称密钥
5. 加密通信

### HTTP状态码
- 2xx：成功
- 3xx：重定向
- 4xx：客户端错误
- 5xx：服务器错误

### 常见协议
- HTTP：超文本传输协议
- HTTPS：安全的HTTP
- DNS：域名解析
- TCP：可靠传输
- UDP：无连接传输
