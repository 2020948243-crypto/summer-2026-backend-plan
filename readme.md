## 前置核心重申（绝对遵守）

1. 两个月**只攻坚基础层70%**，零差异层、零杀手层内容，不碰分布式、中间件、大模型应用、K8s、第二语言，杜绝贪多嚼不烂。
2. 所有学习遵循**先动手、后复盘、再沉淀**，拒绝纯看视频、纯背书、只刷题不总结的无效学习。
3. 作息固定、节奏固定，每周固定休息1天（建议周日），休息日不新增学习任务，仅复盘整理、放松调整。
4. 核心主线：算法刷题保手感 + SpringBoot项目落地 + MySQL/Redis工程底层 + 计网/OS课内基础补强，为大三JVM、并发、分布式、AI推理服务开发铺路。

## 二、四大模块【分阶段学习方法+每日具体任务】

### 模块一：算法刷题（每日上午固定执行·8周分层落地）

**核心学习方法论（全程通用）**

1. 分类刷题，拒绝乱刷：按数据结构、算法思想分模块突破，形成模板思维，而非随缘做题。
2. 15分钟思考法则：每题先独立思考，画思路、定边界、想解法，超时再看题解，杜绝依赖题解。
3. 三遍刷题法：第一遍独立AC，第二遍复盘优化精简代码，第三遍总结模板、适用场景、易错点。
4. 错题闭环：错题不丢弃，每周复盘二刷，保证同类题型不再出错。

**8周分阶段每日任务明细**

**第1-2周：数组、链表、字符串（基础刚需，面试高频）**

每日任务：日均2-3题，优先LeetCode Hot100简单+中等题；重点攻克双指针、滑动窗口、快慢指针、链表反转、字符串切割匹配。

每日复盘：记录数组越界、空指针、区间边界、链表断链等高频错误，整理通用模板。

**第3-4周：二叉树+哈希表（后端算法核心）**

每日任务：日均2题，重点掌握二叉树递归/迭代遍历、层序遍历、路径求和、对称树；哈希表去重、计数、两数之和变种题。

核心目标：克服递归思维盲区，熟练掌握树的深度、广度优先遍历模板。

**第5-6周：动态规划入门+回溯算法**

每日任务：日均2题，DP专攻入门经典题型（爬楼梯、01背包、打家劫舍、最小路径和），固定「状态定义-状态转移-初始值-结果输出」解题步骤；回溯专攻子集、组合、全排列，掌握剪枝逻辑。

**第7-8周：错题复盘+限时模拟**

每日任务：不做新题，每日复盘4-6道前期中等错题；每周参与1次LeetCode周赛，训练限时解题心态和速度，固化解题肌肉记忆。

### 模块二：SpringBoot博客后端项目（每日下午持续迭代）

**核心学习方法论（拒绝视频依赖）**

1. 先搭骨架、后填业务：前期快速跑通基础流程，后期自主迭代，拒绝逐帧抄视频。
2. 问题驱动学习：遇到Bug优先自主排查（日志、接口、SQL、控制台），锻炼工程排查能力。
3. 功能绑定技术点：每做一个功能，必须吃透背后技术原理，做到**做一个、懂一个、会一个**。
4. 全程规范开发：统一返回体、全局异常、日志、注释，贴合企业开发规范，适配简历项目包装。

**8周分阶段项目迭代每日任务**

**第1周：基础骨架搭建（快速落地）**

每日任务：搭建SpringBoot3项目，整合MyBatis-Plus、Knife4j；完成数据库建表、用户、文章基础CRUD；跑通本地接口调试，熟悉项目分层架构（Controller-Service-Dao-Entity）。

**第2-4周：核心业务功能迭代**

每日任务：迭代JWT登录鉴权、SpringSecurity权限控制（游客/用户/管理员）；实现文章分页、分类、标签功能；开发评论、点赞基础功能，每日完成1-2个小功能并完整测试。

**第5-6周：缓存优化+工程完善**

每日任务：整合Redis，实现点赞数据缓存、热点文章缓存；解决缓存基础问题；完善全局异常处理、日志打印、参数校验；优化接口性能。

**第7-8周：部署+重构+简历包装**

每日任务：Linux云服务器搭建环境，Docker容器化部署项目；重构冗余代码、统一代码规范；完善GitHub README（项目介绍、技术栈、功能截图、部署教程、踩坑记录）；整理全套接口文档。

### 模块三：MySQL+Redis（每晚2h·理论+项目落地双闭环）

**核心学习方法论**

1. 场景化学习：所有底层知识点，必须绑定博客项目业务，理解「为什么用、怎么用、不用会有什么问题」。
2. 实操优先：索引、事务、MVCC、缓存问题，全部手动写SQL、改配置、做测试验证，不背死知识。
3. 问题闭环：白天项目遇到的慢查询、缓存失效、数据不一致问题，晚上针对性学原理并优化。

**每日固定学习节奏**

1. 前30分钟：复习昨日底层知识点，口述核心原理；
2. 中间1小时：学习新知识点，手写笔记；
3. 最后30分钟：在项目中实操验证，落地对应优化方案。

**分阶段学习重点**

**1-4周主攻MySQL**：索引底层B+树、聚簇/二级索引、最左匹配、索引失效、Explain执行计划、事务四大隔离级别、MVCC、锁机制、慢查询优化。

**5-8周主攻Redis**：五大基础数据结构业务场景、ZSet排行榜实现、缓存穿透/击穿/雪崩解决方案、Redis实现登录态存储、热点数据缓存、缓存与数据库一致性问题。

### 模块四：计算机基础（碎片查漏·应试+八股双补强）

**核心学习方法**

1. 计网：每日1小节图解网络，吃透核心机制，拒绝碎片化浅读，每节学完手写流程（三次握手、四次挥手、HTTPS加密流程等）。
2. OS：依托天大课内课件、笔记，重点复习进程线程、内存管理、IO模型、并发基础，对接大三JUC、JVM学习。
3. Linux：依托云服务器实操，每日敲10-20个命令，熟练文件操作、权限配置、进程管理、端口查看、Docker基础命令，纯实操不死背。

## 三、每日标准化复盘流程（15分钟搞定，闭环提分）

1. **算法复盘**：今日刷题数、AC率、错题原因、新增解题模板；
2. **项目复盘**：今日完成功能、遇到的Bug及解决方案、明日迭代计划；
3. **基础复盘**：今日掌握的底层原理、可落地的技术点、未吃透的盲区；
4. **明日规划**：提前锁定次日3项核心任务，避免次日迷茫。

## 四、严格执行禁令（绝对不碰·防止精力分散）

1. 不学习Go、Python第二语言；
2. 不接触RabbitMQ、Nacos、Kafka等分布式中间件；
3. 不学K8s、CI/CD、云原生进阶内容；
4. 不碰LangChain、RAG、大模型应用、vLLM、向量数据库、CUDA；
5. 不研究小众框架、低代码工具，所有精力聚焦基础层。
